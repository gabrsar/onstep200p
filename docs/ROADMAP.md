# Status and roadmap

## Bench validated

- ESP32-S3 firmware, SSD1306, joystick calibration and speaker circuit.
- AP/home Wi-Fi, LX200 connectivity and tested Stellarium date/time sync.
- Version/hash reporting and persistent calibration/mute.

## Software follow-up

- Long-running reconnect, Wi-Fi loss/recovery and alternate-profile hardware tests.
- Additional LX200 clients and transport regression coverage.
- Redacted hardware photographs.
- Runtime Wi-Fi setup and optional automatic clock source.

## Before powered telescope use

- Confirm axis wiring, especially ALT10/9/8.
- Measure gearing and configure steps/degree/microstepping.
- Verify current, directions, cooling, power and physical stop.
- Validate limits, cable clearance, alignment, GoTo and tracking.

Optional sensors and extra indicators should follow demonstrated needs.
